# 初級模擬站（認證模擬 · MISSION 01）

模擬 [Lokahsu 原住民族語言能力認證測驗](https://lokahsu.ilrdf.org.tw/web_lokahsu/) **初級** 的題型與作答節奏。
選語言別與方言別後產生一份 30 題的試卷：聽力四部分各 5 題、口說兩部分各 5 題。
**交卷前不給任何回饋**——即時回饋是 MISSION 01／02 的定位，這裡要模擬的是整卷作答的感覺。

## 題型對應

正式初級測驗為「聽力（是非題、選擇題、配合題）、口說（單詞朗讀、簡答題、看圖說話）」。
本站用族語 E 樂園「句型篇國中版」的教材重建其中六種：

| 本站 | 教材來源（klokah） | 作答方式 |
|---|---|---|
| 第一部分：是非題 | typeId 3 看圖識字 | 播族語句、看圖片，選 O／X |
| 第二部分：選擇題(一) | typeId 4 選擇題（一） | 播族語句，從三張圖片選一張 |
| 第三部分：選擇題(二) | typeId 5 選擇題（二） | 讀中文句，從三段族語錄音選一段 |
| 第四部分：配合題 | typeId 6 配合題 | 播一段族語對話，從五張圖片選一張 |
| 口說第一部分：單詞朗讀 | typeId 1 基本詞彙 | 看族語拼寫念出來，ASR 比對 |
| 口說第二部分：簡答題 | typeId 9 簡短對話 | 聽族語問句、用族語回答，**不評分** |

Lokahsu 的題型音檔路徑（`3recognize`／`4choiceOne`／`5choiceTwo`／`6match`）與 klokah 的 typeId
同名同構——兩者是同一批教材，而 klokah 版本以 CC BY-NC-SA 4.0 釋出。

**尚未提供：看圖說話。**

## 與正式測驗不同的地方

頁面上在作答前就會列出這些差異：

- **選擇題(二) 的中文以文字呈現。** 正式測驗會播出中文句子，但教材沒有中文錄音，本站也不做 TTS。
  這讓人有可能用「中文對中文」而不是用聽的來作答；在不做 TTS 的前提下無解。
- **每題都可以重複播放**，正式測驗只播兩遍（本站按一次「播放」也是連播兩遍）。
- **配合題每題的五張圖片來自同一組對話**，正式測驗是五題共用一組圖片。
- 沒有答案卡，直接在畫面上選。

## ⚠️ 音檔由 klokah.tw 直接播放，不入庫

每筆資料帶有 `audioUrl`，播放時瀏覽器直接向 `klokah.tw` 取檔。這是刻意的取捨：
全部下載約 200 MB，而 `.gitignore` 也一律擋所有音檔副檔名。

代價要講清楚：

- 使用者播放時，**klokah.tw 會看到使用者的 IP 位址與瀏覽器資訊**。
  這與 MISSION 01／02（所有素材都由自家 origin 提供）是實質不同的隱私姿態，頁面上已揭露。
- klokah **不送 CORS 標頭**，所以：**不能加 `crossorigin`、不能用 `fetch()` 取音檔**，
  也讀不到 HTTP 狀態。只能監聽 media `error` 事件，外加 15 秒 stall 看門狗（請求卡住時不會有任何事件）。
- 這是一個永久的外部依賴。若 klokah 加上 Referer 檢查或停機，聽力半場會整個降級成閱讀。

**降級行為**：音檔載不出來時揭露該題的族語文字讓題目仍可作答，並把該題標成
`notScored`——不進分母、**不算答錯**。

## ⚠️ 語音辨識是「族級」模型

官方語音辨識只提供 **16 個族級模型**，沒有 42 個方言別模型。42 個方言別**都對得到模型**，
限制是**粒度**不是覆蓋率：選「秀姑巒阿美語」時送出的是「阿美」族的通用模型。
方言差異造成的辨識偏差**是模型的限制，不代表使用者念錯**。

模型對照與 WAV 編碼規則直接沿用 `../body-parts-speaking/asr.mjs`，未另造一套，也未改動 MISSION 02。
錄音膠水層（`recorder.mjs`）是本頁自有的——MISSION 02 的同段程式碼與它的 DOM 綁在一起且未 export，
而它的測試對該檔原始碼做正則斷言，把它抽出來會弄壞 02。

**與 MISSION 02 的關鍵行為差異：任何情況都不停用「開始」。**
聽力四部分完全不需要麥克風，所以辨識服務不可用、麥克風被拒、瀏覽器不支援錄音時，
口說會標成「未作答」或「無法判定」，聽力照常作答，成績單會寫出哪幾節沒作答與原因。

## ⚠️ 不換算成正式分數，也不宣告通過

官方及格標準是「聽力成績須達45分以上，口說成績須達15分以上，始核發該級別之合格證書」，
本站把這句話原文引在成績單上，但**不做任何換算、不預測結果**：

- `report.converted` 永遠是 `null`。
- 成績單物件裡沒有 `pass`／`passed`／`合格` 這類欄位；「合格」二字只出現在官方原文引用裡。
- 成績單只顯示「答對 N / 20 題」與「正確率 X%（以已作答且可計分的 M 題為分母）」。
- **未作答**、**音檔失敗不計分** 是兩個分開的桶，都不進分母、都不算錯。
- **簡答題完全不評分**（`scored: false`）——正式測驗由委員評分，機器沒有辦法判斷回答是否合適，
  這裡只顯示系統聽到的內容。

單詞朗讀只做字面比對（`exactMatch`），不呼叫翻譯服務：單一詞彙的中文註解沒辦法可靠地跟
機器翻譯比對，而錯誤的「不相符」正是要避免的事。辨識失敗、逾時、沒回文字一律是
`undetermined`，**不是 `mismatched`**。

## 無障礙

- 選項是 `<fieldset>` 內的原生 `<input type="radio">`，方向鍵導覽免費取得；換題時焦點移到題號。
- 選擇題(二) 的播放按鈕刻意放在 `<label>` 外面——點播放不會順手選中該選項。
- **圖片選項的 `alt` 是空的。** 寫出圖片內容等於直接洩漏是非題與選擇題(一) 的答案。
  這是真實限制，頁面上已揭露；同時說明**選擇題(二) 完全以聽力作答**，不需要視覺。
- 錄音與播放狀態一律「圖示＋文字」，不靠顏色單獨表意；`prefers-reduced-motion` 下不做脈動動畫，
  兩遍之間也不留間隔。

## 試卷編號

每份試卷由一個 32-bit seed 決定，畫面上顯示成 7 碼的試卷編號。
同一個編號＋同一個方言別必定產生同一份試卷，方便對答案或發同一份卷子：

```text
/apps/beginner-mock-exam/?paper=1F3K9ZQ
```

## 檔案

| 檔案 | 用途 |
|---|---|
| `paper.mjs` | 出卷器。純函式、無 DOM、無 fetch，`createPaper` 內不用 `Math.random` 或 `Date`。 |
| `scoring.mjs` | 計分。誠實性規則都寫在這裡，每一條都有測試。 |
| `recorder.mjs` | 麥克風、WAV 轉檔、`asr_transcribe`。規則全部 import 自 `asr.mjs`。 |
| `app.mjs` | DOM 控制、音檔播放與降級、成績單渲染。 |

## 測試

```bash
node apps/beginner-mock-exam/tests/run.mjs
```

完全離線執行，涵蓋：42 個分片的資料契約（含每個 `imagePath` 真的存在、
`data/klokah-junior/` 下沒有任何音檔）、200 個 seed × 3 個方言的出卷不變量
（是非題不得整節同一個答案、干擾圖必須同類別、配合題 A→1…E→5 的字母與圖片對應、
簡答題物件不得有 `answerKey`／`expected` 欄位）、計分的誠實性規則、
頁面契約（七項揭露都在作答區之前、四段官方指示原文逐字相符、不得有 `crossorigin`）、
音檔降級，以及沿用 MISSION 02 的口說紅線（不得由代碼前綴推導模型、不得送出原始錄音、
不得出現斷言發音的措辭、不得使用任何瀏覽器儲存）。
