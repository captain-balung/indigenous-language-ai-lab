# 市場小幫手（情境應用 MISSION 02）

媽媽給 100 元，並依本局抽到的品項交代購物清單（例如買香蕉、空心菜跟鳳梨）。族語練菜／水果貨品名；介面與任務說明全是中文。沒有配分；結果只存在當次頁面。

價目與過關條件由程式判定，不用 LLM 當攤主。

## 任務

| 項目 | 內容 |
| --- | --- |
| 預算 | 100 元 |
| 貨品 | 自[學習詞表／植物](https://web.klokah.tw/vocabulary/)可賣詞中，**每局隨機抽 3 種**；任務說明會寫出這三樣 |
| 價目 | 三種角色隨機套用：一個 10 元；3 個 30 元；論斤 50 元／約 5 個 |
| 過關 | 清單上每樣至少買一個，總額 ≤ 100 |
| 失敗 | 超過預算；或清單還沒買齊 |

論斤貨先只報「論斤」；問「一斤大約幾個？」才補細節。殺價一律拒絕。

## 作答

1. STEP 1 選語言別與方言別，開始任務後設定區收起。
2. **問價**：點貨品 → 用族語說出該貨品名（可聽教材）→ 攤主用中文報價。三種都問過才能進購買。
3. **購買**：選數量（中文 UI）→ 再說一次族語貨品名放入籃子 → 結帳。
4. 「再玩一次」會重新隨機抽貨；「回到設定」保留語言／方言、清空進度。
