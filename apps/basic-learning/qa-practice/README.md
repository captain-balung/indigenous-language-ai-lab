# 問答練習（MISSION 04）

聽國中版對話問句，用打字或錄音自由回答。沒有標準答案。系統會顯示它聽到、懂成的意思，並粗分成「有答到／再想想／無法判定」，不顯示考試配分。

失敗（辨識或翻譯中斷）不判錯。對錯只存在當次頁面，不寫入瀏覽器儲存。

## 作答

1. 選語言別與方言別。
2. 播放族語問句；可選擇顯示中文問句當提示。
3. 打字或錄音後送出。錄音會先辨識，再翻成中文做粗判。

## 本機預覽與測試

```
node apps/basic-learning/qa-practice/tests/run.mjs
node scripts/serve.mjs 4173
```

開啟 `http://127.0.0.1:4173/apps/basic-learning/qa-practice/`。
