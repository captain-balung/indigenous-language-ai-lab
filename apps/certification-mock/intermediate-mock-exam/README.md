# 中級模擬站（認證模擬 · MISSION 02）

模擬 [Lokahsu 原住民族語言能力認證測驗](https://lokahsu.ilrdf.org.tw/web_lokahsu/) **中級** 的題型與作答節奏。
選語言別與方言別後產生一份 31 題的練習卷：口說（單句朗讀 5、問答題 5、看圖表達 1）＋聽力四部分各 5 題（作答順序為口說先、聽力後）。
**練習導向**：每題選好答案後按「確定」，立刻顯示對錯；可隨時「結束練習」查看摘要。

## 題型對應

官方 Q&A 對中級的定義是「聽力（是非題、選擇題）、口說（單句朗讀、問答題、看圖表達）」。
本站用族語 E 樂園「句型篇高中版」的教材重建其中七種：

| 本站 | 教材來源（klokah 高中版） | 作答方式 |
|---|---|---|
| 口說第一部分：單句朗讀 | typeId 8 唸唸看 | 看族語整句念出來；ASR 比對**詞語重疊程度** 0–3 分 |
| 口說第二部分：問答題 | typeId 9 簡短對話 | 聽族語問句、用族語回答；ASR→翻譯→粗判；合理 **3 分** |
| 口說第三部分：看圖表達 | typeId 10 看圖說話 | 一張圖＋中文提示；ASR→翻譯→對照參考答案 **0–10 分** |
| 第一部分：是非題 | typeId 3 看圖識字 | 播族語句、看圖片，選 O／X |
| 第二部分：選擇題(一) | typeId 4 選擇題（一） | 播族語句，從三張圖片選一張 |
| 第三部分：選擇題(二) | typeId 5 選擇題（二） | 讀中文句，從三段族語錄音選一段 |
| 第四部份：選擇題(三) | typeId 7 選擇題（三） | 播族語句，從三個拼寫文字選一個 |

Lokahsu 的題型音檔路徑（`3recognize`／`4choiceOne`／`5choiceTwo`／`7choiceThree`／
`8oralReading`／`9dialogue`／`10pictureTalk`）與 klokah 的 typeId 同名同構——兩者是同一批教材，
而 klokah 版本以 CC BY-NC-SA 4.0 釋出。

「第四**部份**」的「份」字是官方原文，不是錯字，測試會逐字比對。

## 與初級（國中版教材）的四個結構差異

1. **選擇題(一) 的干擾圖是抽出來的。** 高中版每題只有一張圖與一段對話錄音，不像國中版三個選項各自有圖有音，
   所以另外兩張圖抽自**同一個類別**的別題。
2. **選擇題(三) 是高中版才有的題型**（國中版對應位置是配合題），純文字＋音檔；三個拼寫選項同樣抽自同類別。
3. **看圖表達只有一張圖**（國中版是四張），而且教材的兩個題目都可用，每次隨機抽一題。
4. **單句朗讀是整句**（國中版是單詞），所以判定方式必須跟著換，見下。

## 與正式測驗不同的地方

頁面上在作答前就會列出這些差異：

- **選擇題(二) 的中文以文字呈現。** 正式測驗會播出中文句子，但教材沒有中文錄音，本站也不做 TTS。
- **每題都可以重複播放**，正式測驗只播兩遍（本站按一次「播放」也是連播兩遍）。
- **選擇題(一)(三) 的干擾選項抽自同類別的別題**，正式測驗的干擾項由命題委員挑選。
- 沒有答案卡，直接在畫面上選；按「確定」後立刻顯示對錯（正式測驗交卷前不會給回饋）。

### ⚠️ 選擇題(三) 的族語拼寫在作答前就看得到

其餘聽力節次一律遵守「按確定之前絕不渲染族語文字」，但選擇題(三) 的題型本身就是
「從三個拼寫文字裡選出你聽到的那一句」——**選項就是題目**，不先顯示就沒有題目可作答。

連帶的一個後果：這一節**不做**「音檔載不出來就揭露族語文字」的降級，因為那等於直接給答案。
該題改為標成不計分，並說明這一節必須用聽的。選擇題(二) 也走同一條路（那一節本來就只能用聽的）。

### ⚠️ 口說三段的作答說明是本站措辭

Lokahsu 的「考試題型」頁面明講「考試題型僅提供聽力測驗」，所以**只有四段聽力有官方原文**，
本站逐字引用；三段口說的說明由本站撰寫。`SECTION_SPECS` 每一節都帶
`instructionSource: "official" | "site"`，頁面與測試都據此區分，不把自撰文字冒充官方原文。

## ⚠️ 音檔與看圖表達圖由 klokah.tw 直接載入，不入庫

每筆聽力／口說音檔帶有 `audioUrl`；看圖表達另帶 `imageUrls`（一張圖）。
瀏覽器直接向 `klokah.tw` 取檔。代價與初級模擬站相同：

- 使用者播放或載圖時，**klokah.tw 會看到使用者的 IP 位址與瀏覽器資訊**，頁面上已揭露。
- klokah **不送 CORS 標頭**，所以：**不能加 `crossorigin`、不能用 `fetch()` 取音檔**，
  也讀不到 HTTP 狀態。只能監聽 media `error` 事件，外加 15 秒 stall 看門狗。
- 這是一個永久的外部依賴。若 klokah 加上 Referer 檢查或停機，聽力半場會整個降級。

**降級行為**：音檔載不出來時把該題標成 `notScored`——不進分母、**不算答錯**；
是非題與選擇題(一) 另外揭露該題的族語文字讓題目仍可作答，選擇題(二)(三) 則不揭露（文字就是答案）。

## ⚠️ 單句朗讀為什麼不用字面完全相符

初級的單詞朗讀用 `exactMatch`：單一個詞，要嘛一樣要嘛不一樣。中級是**整句**，
族級模型對方言的辨識偏差幾乎保證整句不會逐字相同——沿用 `exactMatch` 等於用模型的限制
去判使用者念錯，違反本站的誠實性原則。

因此改為 `judgeSentenceReading`：把 ASR 文字與教材整句都正規化後切詞，取**詞語多重集合的 F1**：

| 重疊率 | 分數 | 狀態 |
|---|---|---|
| ≥ 0.9 | 3 | `matched`（幾乎完全重疊） |
| ≥ 0.7 | 2 | `partial`（部分重疊） |
| ≥ 0.5 | 1 | `partial` |
| < 0.5 | 0 | `mismatched`（重疊很少） |
| 沒有辨識結果 | — | `undetermined` |

用 F1 而不是單看命中率，是為了讓「多念一堆不相干的詞」也會扣分。
撇號（`luma’`）是族語正寫法的一部分，切詞時**不當標點吃掉**，只統一彎／直引號。
布農、邵等語言會把「天黑了！」說成單一個多式綜合詞——那仍然是一整句，不是單詞題。

畫面與成績單一律用「與教材拼寫的重疊程度」描述結果，**不出現任何斷言發音對錯的措辭**。

## ⚠️ 語音辨識是「族級」模型

官方語音辨識只提供 **16 個族級模型**，沒有 42 個方言別模型。42 個方言別**都對得到模型**，
限制是**粒度**不是覆蓋率。方言差異造成的辨識偏差**是模型的限制，不代表使用者念錯**。

模型對照與 WAV 編碼規則直接沿用 `../body-parts-speaking/asr.mjs`，未另造一套。
錄音膠水層（`recorder.mjs`）是本頁自有的複本——理由與初級模擬站相同：鄰居的同段程式碼
與其 DOM 綁在一起且未 export，而它們的測試對該檔原始碼做正則斷言，把它抽出來會弄壞鄰居。

**任何情況都不停用「開始」。** 聽力四部分完全不需要麥克風，所以辨識服務不可用、麥克風被拒、
瀏覽器不支援錄音時，口說會標成「未作答」或「無法判定」，聽力照常作答。

## ⚠️ 練習得分依公開配分，但不宣告正式通過

官方及格標準是「初級與中級測驗採分項合格制度，考生須同時通過聽力與口說兩項測驗，
其中聽力成績須達45分以上，口說成績須達15分以上，始核發該級別之合格證書」，
本站把這句話原文引在成績單上。練習得分依公開配分加總（口說 40＋聽力 60＝100），但**不預測是否通過**：

| 區塊 | 配分 |
|---|---|
| 口說·單句朗讀 | 每題 0–3 分，共 15 分 |
| 口說·問答題 | 每題 3 分，共 15 分 |
| 口說·看圖表達 | 共 10 分（0–10） |
| 聽力·是非／選一／選二／選三 | 各每題 3 分，各共 15 分（聽力合計 60） |

- `report.converted` 永遠是 `null`（練習得分在 `report.practice`，不包裝成正式換算成績）。
- 成績單物件裡沒有 `pass`／`passed`／`合格` 這類欄位；「合格」二字只出現在官方原文引用裡。
- **未作答**、**音檔失敗不計分** 是兩個分開的桶，都不進正確率分母、都不算錯（該題得 0 分）。
- **問答題**合理得 3 分、不太合理得 0 分（教材無標準答案；非正式委員評分）。
- **看圖表達**給 0–10 分（非正式委員評分）。

辨識失敗、逾時、沒回文字一律是 `undetermined`，**不是 `mismatched`**（該題得 0 分，但不宣稱你念錯）。

## 無障礙

- 選項是 `<fieldset>` 內的原生 `<input type="radio">`，方向鍵導覽免費取得；換題時焦點移到題號。
- 選擇題(二) 的播放按鈕刻意放在 `<label>` 外面——點播放不會順手選中該選項。
- **圖片選項的 `alt` 是空的。** 寫出圖片內容等於直接洩漏是非題與選擇題(一) 的答案。
  這是真實限制，頁面上已揭露；同時說明**選擇題(二)(三) 不需要視覺**——(二) 純聽力，
  (三) 是聽了之後比對文字選項。
- 錄音與播放狀態一律「圖示＋文字」，不靠顏色單獨表意；`prefers-reduced-motion` 下不做脈動動畫。

## 試卷編號

每份試卷由一個 32-bit seed 決定，畫面上顯示成 7 碼的試卷編號。
同一個編號＋同一個方言別必定產生同一份試卷：

```text
/apps/certification-mock/intermediate-mock-exam/?paper=1F3K9ZQ
```

## 檔案

| 檔案 | 用途 |
|---|---|
| `paper.mjs` | 出卷器。純函式、無 DOM、無 fetch，`createPaper` 內不用 `Math.random` 或 `Date`。 |
| `scoring.mjs` | 計分。誠實性規則都寫在這裡，每一條都有測試。 |
| `semantic-judge.mjs` | 問答題／看圖表達的語意評分介面；預設規則粗判，可換成 `createLlmSemanticJudge`。 |
| `recorder.mjs` | 麥克風、WAV 轉檔、`asr_transcribe`。規則全部 import 自 `asr.mjs`。 |
| `app.mjs` | DOM 控制、音檔播放與降級、成績單渲染。 |

## 測試

```bash
node apps/certification-mock/intermediate-mock-exam/tests/run.mjs
```

完全離線執行，涵蓋：42 個分片的資料契約（含每個 `imagePath` 真的存在、
`data/klokah-senior/` 下沒有任何音檔、邵語少兩題的例外必須明列）、200 個 seed × 3 個方言的
出卷不變量（是非題不得整節同一個答案、干擾圖／干擾句必須同類別且與目標相異、選擇題(三) 三個拼寫互異、
問答題物件不得有 `answerKey`／`expected`、兩題看圖表達都抽得到）、計分的誠實性規則與
`judgeSentenceReading` 的門檻邊界、頁面契約（揭露都在作答區之前、四段官方指示原文逐字相符、
口說三段標記為本站措辭、不得有 `crossorigin`）、音檔降級（含選擇題(三) 不揭露文字的分支）、
口說紅線（不得由代碼前綴推導模型、不得送出原始錄音、不得出現斷言發音的措辭、不得使用任何瀏覽器儲存），
以及「沒有動到鄰居」。
