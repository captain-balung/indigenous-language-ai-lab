# 十二年國教（課堂測驗 MISSION 05）

看十二年國教課程原住民族語文教材第 1–9 階的族語句子，直接錄音念出來。一輪 8 題，句子從選定階級隨機抽出；每題只錄一次。

題目主畫面只顯示族語文字，中文翻譯在作答結果才出現。課堂練習不提供提示；教材範例音檔在送出答案並完成判定後才出現，作答前不載入、也不能播放。錄音按鈕一開始就能按。

判定順序：語音辨識 → 與教材字面比對 → 翻譯樣板比對 → 樣板沒過時送自架 vLLM 做 AI 意思判別。與教材字面一致時不另外呼叫翻譯。辨識或翻譯中斷不計分，不當成使用者念錯。

## 本機預覽與測試

```
node apps/classroom-quiz/twelve-pronunciation/tests/run.mjs
node scripts/serve.mjs 4173
```

開啟 `http://127.0.0.1:4173/apps/classroom-quiz/twelve-pronunciation/`。

## 教材與音檔

題目來自「族語 E 樂園」十二年國教課程原住民族語文教材，只收第 1–9 階。音檔不入庫，作答完成後才由官方 CloudFront 直接播放；播放時該站會看到使用者 IP。
