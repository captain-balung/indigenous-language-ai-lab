# 看圖測驗（MISSION 04）

初級看圖說話，四張圖一起看，用自己的話描述。評分與看圖描述相同（字面一致，否則翻譯後語意評分）。每題只送出一次，做完看本堂分數。

每方言目前只有 1 題。出題上限沿用課堂的 8 題，題庫變多才會湊滿，不會把同一題重複排出來。

## 本機預覽與測試

```
node apps/classroom-quiz/picture-quiz/tests/run.mjs
node scripts/serve.mjs 4173
```
