# 意思造句（MISSION 01）

只看中文意思，自己寫族語。每題都翻譯，並顯示系統懂成。一輪 8 題，每題只送一次。字面已與教材一致時，翻譯中斷仍算通過；否則中斷不計分。分數只留在這一輪畫面。

出題與計分的共用程式在這個資料夾，看圖口說、聽後轉述、接話小考會引用這裡。
