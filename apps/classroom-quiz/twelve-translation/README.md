# 十二年國教（課堂測驗 MISSION 06）

看十二年國教課程原住民族語文教材第 1–9 階的中文句子，用錄音或打字翻成族語。一輪 8 題，句子從選定階級隨機抽出。

作答方式在題目頁用「語音／打字」按鈕切換，不需要在設定區先選：

- **錄音**：錄音一次，語音辨識後走判定流程。
- **打字**：直接寫族語，送出後翻譯成中文再比對。

沒有語音辨識模型的方言會自動使用打字。判定順序：字面完全比對 → 翻譯樣板比對 → 樣板沒過時送自架 vLLM 做 AI 意思判別（`apps/shared/semantic-meaning.mjs`），失敗維持本來的再試試看。只送譯文與教材中文，不送參考族語句。翻譯不判發音，錄音模式只把辨識文字當作答內容。

## 本機預覽與測試

```
node apps/classroom-quiz/twelve-translation/tests/run.mjs
node scripts/serve.mjs 4173
```

開啟 `http://127.0.0.1:4173/apps/classroom-quiz/twelve-translation/`。

## 教材與音檔

題目來自「族語 E 樂園」十二年國教課程原住民族語文教材，只收第 1–9 階。音檔不入庫，執行時由官方 CloudFront 直接播放；播放時該站會看到使用者 IP。作答前不播答案音檔，送出後才顯示教材族語與音檔。
