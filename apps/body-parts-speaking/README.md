# 身體部位口說練習（MISSION 02）

「身體部位練習」的口說版本：**題目、教材與判定邏輯與打字版完全相同，差別只在作答方式**——
01 用打字，02 用說的。

選語言別與方言別後，系統從該方言的 10 筆教材隨機抽題，顯示圖片並問「這是什麼？」，
使用者按下錄音、用族語念出完整句子，系統以語音辨識取得族語文字，再走與 01 相同的兩層判定。

## 判定流程

```text
錄音 → 轉成 16 kHz 單聲道 WAV → asr_transcribe 取得族語文字
  → A. 與教材答案正規化整句比對 → 相符即通過（不呼叫翻譯服務）
  → B. 不相符 → translate_to_zh → 十類身體部位受控同義詞判定
  → C. 任一步失敗 → 不判錯，保留該題與錄音
```

判定邏輯（正規化、同義詞表、抽題）直接沿用 `../body-parts-practice/core.mjs`，
未另造一套，也未改動打字版的行為。

## ⚠️ 語音辨識是「族級」模型

官方語音辨識只提供 **16 個族級模型**，沒有 42 個方言別模型。
選「秀姑巒阿美語」時，實際送出的是「阿美」族的通用模型。

方言別選擇的用途是**挑選教材與判定語意**，不影響辨識模型。
方言之間的詞彙與音韻差異可能造成辨識偏差，**這是模型的限制，不是使用者念錯**。
這件事寫在頁面上錄音前就看得到的位置。

### 族 → 模型對照是寫死的，不做任何推導

`asr.mjs` 的 `ASR_MODELS` 明確列出 16 族對應的模型 ID，載入時以即時 `asr_dialects` 校驗：

- 對照表有、即時清單沒有 → 該族標示為暫時無法辨識，開始按鈕停用。
- 即時清單有、對照表沒有 → `console.warn` 明確警告，不靜默吞掉。
- **任何情況都不退回前綴推導或模糊比對。**

> **為什麼不能用代碼前綴推導**：賽德克三個方言的語言代碼是 `trv_Duda`／`trv_Tegu`／`trv_Delu`，
> 但辨識要送 `formosan_sdq`；太魯閣語是 `trv_Truk`，要送 `formosan_trv`。
> 四個方言前綴都是 `trv` 卻分屬兩個模型——用前綴推導會把賽德克的錄音送進太魯閣模型。

## ⚠️ 錄音一律轉成 16 kHz 單聲道 PCM WAV 才送出

直接送瀏覽器預設的 WebM/Opus，辨識服務會回傳**與原句無關的文字**，而且仍是 HTTP 200
與非空字串——看起來像成功。因此：

- 送出前於前端轉檔：`decodeAudioData` → `OfflineAudioContext` 降單聲道並重取樣 → 自寫 RIFF/WAVE 標頭。
  **純前端、零外部函式庫、零 CDN。**
- 錄音時關閉 `echoCancellation`／`noiseSuppression`／`autoGainControl` 並指定單聲道；
  瀏覽器不支援這些約束時優雅退回並警告。
- **轉檔失敗絕不靜默送出原始錄音**：顯示明確錯誤並提供重錄，且不發出任何請求。
- 辨識逾時 45 秒（其餘請求 20 秒）；等待超過 5 秒會說明還在辨識中。

## 不會因為機器聽錯就說使用者念錯

- **每次判定都顯示「系統聽到的是：⟨辨識文字⟩」**，讓使用者自己判斷是自己念錯還是機器聽錯。
- 判定不通過時只陳述「系統聽到的內容與本題不相符」，**不使用任何斷言發音錯誤的措辭**。
- 一律提供重新錄音與查看教材答案。
- 辨識回空字串、逾時、HTTP 非成功、`ok:false`、缺欄位 → 顯示無法辨識，
  **不記為答錯**，保留該題與錄音。

## 隱私

- 錄音會傳送至 `ai3.iformosa.com.tw` 交由語音辨識服務處理；本站不儲存、不轉送給該服務以外的任何對象。
- 錄音只存在當次頁面狀態，切題、重錄與離開頁面都會 `URL.revokeObjectURL` 釋放。
- **不寫入 localStorage、sessionStorage、IndexedDB、cookie 或任何遠端儲存**；沒有帳號、沒有追蹤。
- `.gitignore` 擋住 `*.wav` `*.mp3` `*.ogg` `*.flac` `*.m4a` `*.webm`，錄音不會進版本庫。

## 無障礙與降級

- 錄音狀態（未錄音／錄音中／轉檔中／辨識中／完成／失敗）**同時有圖示與文字**，不靠顏色或動畫單獨表意。
- 所有操作鍵盤可達；狀態訊息使用 `aria-live`；支援 `prefers-reduced-motion`。
- **麥克風權限被拒**：說明原因並提供改用打字版的路徑。
- **瀏覽器不支援錄音**：停用開始按鈕並引導改用打字版。
- 390×844 與桌機寬度皆無水平溢出。

## 測試

```bash
node apps/body-parts-speaking/tests/run.mjs
```

涵蓋：16 族模型對照與唯一性、**賽德克／太魯閣同前綴不同模型的專項測試**、
對照表與即時清單三條分支、16 kHz 單聲道 16-bit RIFF/WAVE 輸出、
轉檔失敗不得送出原始錄音、判定 fixture（完全相符不呼叫翻譯服務／排版差異／少字不放行／
語意通過／語意不通過／各種失敗一律不判錯）、重複送出只一個有效請求、切換語別清空舊狀態。
