# 字母篇例詞

本目錄保存「族語 E 樂園」補充教材字母篇的例詞，供「跟唸」與「發音練習」使用。

- 42 個方言別，共 4865 個例詞。
- 每個字母是一課，例詞是該課的句子。題面用課名「字母 a」標出所屬字母。
- `dialects/{dialectId}.json`：每個方言一個分片，頁面只載入使用者選的那一個。
- `dataset.json`：索引、來源與完整性數字。**不含題目本身。**
- `manifest.json`：來源 URL、檔案大小與 SHA-256。
- `LICENSE.md`：授權、標示與使用限制。

字母本身的發音與圖片不在這個練習裡。

## 音檔

**音檔不入庫。** 例詞帶有 `audioUrl`，執行時由 klokah.tw 直接播放。
這代表使用者播放時，該站會看到使用者的 IP 位址；應用頁面必須揭露這件事。

## 重新下載

```
node scripts/download-alphabet.mjs
```

下載器會要求 42 個方言、每個方言至少 8 個不重複例詞，全部驗證通過才寫檔。失敗時本目錄保持原狀。

其他參數：`--dry-run`（不寫檔的抽驗）、`--dialects=1,24,33`（只抓部分方言，需搭配 `--dry-run`）、
`--verify-audio`（每方言首尾 HEAD 抽驗）、`--verify-audio=all`（完整掃描）。
